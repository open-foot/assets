## Design authority

The canonical visual authority is [DESIGN.md](DESIGN.md). Portable foundations
live in `tokens/`, and `brand/manifest.json` classifies current masters,
derivatives, and legacy references. Placement and accessibility rules live in
[`brand/README.md`](brand/README.md) and
[`brand_usage_guide.md`](brand_usage_guide.md). Product consumers use semantic
roles instead of recoloring raster files or copying raw values into local
documentation.
