# OpenFoot brand assets

The transparent positive mark is for light backgrounds; the inverse mark is
for dark backgrounds. Use the lockup when the product name is not already
visible. Use the app-icon and favicon sources only inside their provided Volt
containers.

Keep clear space equal to the ball diameter around a mark or lockup. Do not
stretch, rotate, outline, recolor, crop, or add another accessible name when
visible `OpenFoot` text already labels the same link.

Run `npm test` after generation. The manifest records the source revision,
classification, and SHA-256 checksum for every governed file.
